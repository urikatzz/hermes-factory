## Limits and implementation decisions

- No paid model trial or production task was launched. Synthetic benchmark reports show reporting mechanics, not measured model quality or cost savings. Real comparisons require operator-run private trials.
- Evidence is operator-imported; hashes prove local byte consistency, not independent authenticity. The small functional graders share a process with candidate code and are not tamper-resistant. Automatic promotion and full managed-graph sandbox execution are outside this delivery.
- Built in a separate temporary directory and copied only new source paths into this project, preserving prior untracked deliveries. No Git commit, push or branch change was made.
- The importer uses a small list container that retains variant/provenance metadata for empty result sets; otherwise no-trial reports would lose configured variants.
- Installed routing was checked by generating actual cards without dispatching workers. Actual model adherence and performance remain unmeasured.
- Malformed profile validation was included in the review fix pass to satisfy the explicit input-validation contract.

The execution ledger records these decisions and their practical costs. All source and evidence are retained because there is no authorized Git commit to serve as their durable record.
